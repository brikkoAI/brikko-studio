# @brikko/studio-core

Brikko Studio Core — Node.js agent runtime, forked from OpenClaw under the MIT license.

This package is the fork base. It retains OpenClaw's plugin system, MCP manager, memory layer, and channel adapters. Branding has been replaced with Brikko. The CLI binary is `brikko-studio`.

For the full Studio (with OAuth client, web UI, anonymizer sidecar), see the monorepo root README.
