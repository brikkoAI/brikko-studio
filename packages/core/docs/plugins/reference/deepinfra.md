# DeepInfra plugin

Adds DeepInfra model provider support to Brikko Studio.

## Distribution

- Package: `@brikko-studio/deepinfra-provider`
- Install route: included in Brikko Studio

## Surface

providers: deepinfra; contracts: imageGenerationProviders, mediaUnderstandingProviders, memoryEmbeddingProviders, speechProviders, videoGenerationProviders
