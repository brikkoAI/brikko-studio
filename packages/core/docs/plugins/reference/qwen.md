# Qwen plugin

Adds Qwen, Qwen Cloud, Model Studio, DashScope model provider support to Brikko Studio.

## Distribution

- Package: `@brikko-studio/qwen-provider`
- Install route: included in Brikko Studio

## Surface

providers: qwen, qwencloud, modelstudio, dashscope; contracts: mediaUnderstandingProviders, videoGenerationProviders
